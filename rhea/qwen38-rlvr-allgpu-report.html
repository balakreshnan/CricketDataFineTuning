Qwen3.8-27B with RLVR, rerun with every GPU measured

Qwen3.8-27B was trained with reinforcement learning with verifiable rewards on T20 cricket questions for a second time (Rhea job 47941, 14 Nov 2026), with the same settings as the first run except 120 training steps instead of 100, and with utilisation, memory and power logged on all 32 GPUs. The model answered questions itself and was rewarded only for a correct final number, with a small bonus for shorter answers.
