Speculative decoding on Rhea: does a small draft model make Qwen3.8-27B faster?

How speculative decoding works, and a replay of the race

A small draft model guesses the next few tokens. The large target model checks all the guesses in one pass, keeps the ones it agrees with, and supplies the next token itself. The answer is always the target's; only the speed changes. The replay below is a simulation built from this run's measurements for the chosen configuration: the measured share of accepted guesses and the estimated time of one draft pass and one checking round.
